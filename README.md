# Zapret DPI & VPN Manager

Современный графический интерфейс (GUI) для **Zapret DPI Bypass** и встроенного **VPN/Прокси-клиента** под Windows (WPF .NET 8).

![Zapret GUI](https://raw.githubusercontent.com/bbqabsolute/zapret-gui/main/preview.png) *(при наличии скриншота)*

---

## ✨ Основные возможности

### 🚀 Управление Zapret DPI
- **22 встроенные BAT-стратегии** (general, ALT, FAKE TLS AUTO, SIMPLE FAKE и др.) с автоматическим парсингом и возможностью ручной правки аргументов `winws.exe`.
- **Автономный запуск (Standalone)** или **установка в виде системной службы Windows** с автозапуском при старте системы.
- **Поддержка Game Filter**: фильтрация игровых портов UDP/TCP (1024–65535) для Discord и онлайн-игр.
- **Режимы фильтрации IPSet** (`ipset-all.txt`, any, none).
- **Управление фейками**: выбор и переключение фейковых бинарных файлов (`.bin`).

### 🛡️ VPN и Прокси (BETA)
- **Поддержка протоколов**: `VLESS` (Reality/XTLS-Vision), `VMess`, `Shadowsocks`, `Trojan`, `WireGuard`, `Hysteria2`, `SOCKS5`, `HTTP`.
- **Импорт**: вставка одиночных ссылок, пакетный импорт (многострочный текст), Base64-подписки и ссылки на подписки (URL).
- **Автоматическая установка ядра sing-box**: при первом подключении или тесте ядро автоматически скачивается из официального репозитория GitHub в папку `bin/`.
- **Автоматическая настройка системного прокси Windows** (WinINet) с гарантированным сбросом при отключении или выходе из приложения.

### 🌐 Проверка прокси через HTTP GET
- **Честный тест соединения**: выполнение HTTP GET-запроса через туннель прокси к проверочным сервисам (ipwho.is / Cloudflare trace / ipapi / ipify).
- Отображение **реального пинга (RTT в мс)**, **внешнего IP**, **страны/города** (с эмодзи-флагом) и **провайдера (ASN / ISP)**.
- Цветная индикация задержки: зеленый (<100 ms), желтый (<300 ms), красный (>300 ms).

### 🎨 Дизайн и удобство
- **Windows 11 Fluent Dark** интерфейс с плавной адаптацией под системное масштабирование (PerMonitorV2 DPI Aware).
- **Сворачивание в системный трей** с быстрым управлением и уведомлениями.
- **Диагностика**: 9 проверок системы (права администратора, драйвер WinDivert, служба BFE, конфликтующие VPN и др.).
- **Редактор списков доменов и IP**: встроенный удобный интерфейс для списков исключений и автообхода.

## 🚀 Запуск и использование

1. Скачайте репозиторий или готовый `ZapretGUI.exe`.
2. Запустите `ZapretGUI.exe` (для установки службы и работы драйвера WinDivert рекомендуются права администратора).
3. Выберите стратегию обхода на вкладке **Управление** и нажмите **Запустить Zapret**.

---

## 🛠️ Сборка из исходников

Требуется установленнный **.NET 8 SDK**.

```bash
# Клонирование репозитория
git clone https://github.com/bbqabsolute/zapret-gui.git
cd zapret-gui

# Запуск тестов
dotnet run --project gui_tests/ZapretTests.csproj

# Сборка единого исполняемого файла ZapretGUI.exe
dotnet publish gui_src/ZapretGUI.csproj -c Release -r win-x64 -p:PublishSingleFile=true --self-contained false -o .
```
